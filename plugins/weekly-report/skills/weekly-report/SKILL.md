# 주간 성과 보고서

화면 틀은 고정하고(같은 순서·같은 디자인), 채우는 숫자만 사람마다 다르게 한다. 디자인을 매주 바꾸지 않는 것이 이 스킬의 핵심이다 — 지난주와 나란히 비교할 수 있어야 한다.

## 0. 설정 파일 확인
작업 폴더에 `weekly-report.config.json` 이 있으면 읽고 1단계를 건너뛴다. 없으면 1단계.

## 1. 첫 설정(한 번만, 질문은 한 번에 묶어서)
아래를 물어 `weekly-report.config.json` 으로 저장한다(형식은 `references/config.example.json`).
1. 사업 이름 · 무엇을 파는지 한 줄 · 보고서를 누구에게 보여 주나(나 혼자 / 팀 회의 / 투자자)
2. 한 주의 기준 — 시작 요일, 시간대(예: 수 00:00 → 화 23:59, Asia/Seoul)
3. 퍼널 단계 3~7개 — 방문 → … → 돈이 들어오는 순간. 각 단계를 **어디서 세는지**(분석 도구 이벤트 / 자체 DB / 결제 도구)도 같이.
   예: 방문(GA4) → 신청 클릭(GA4 이벤트) → 회원가입(DB) → 첫 사용(DB) → 결제(Stripe)
4. 쓰는 도구에 체크 — 분석(GA4·네이버 애널리틱스·웹사이트 빌더 기본 통계·Plausible·없음), 광고(메타·구글·네이버 검색광고·카카오모먼트·틱톡·없음), SNS(인스타·틱톡·유튜브·블로그·스레드·카톡 채널), 가입/주문 데이터(자체 DB·스마트스토어·Shopify·구글 폼/시트), 결제(Stripe·Square·토스)
5. 각 도구에서 숫자를 어떻게 가져올지 — API·CLI 가 있으면 그걸, 없으면 **CSV 내보내기나 화면 캡처**. 도구별 어디를 캡처하면 되는지는 `references/channel-recipes.md`.
6. 통화·숫자 표기, 브랜드 색(선택)

없는 채널은 억지로 채우지 않는다 — 해당 섹션은 빈 배열로 두면 "아직 연결 안 됨"으로 보인다.

## 2. 이번 주 숫자 모으기
- 설정의 도구별로 숫자를 모은다. 사용자가 캡처·CSV 를 주면 읽어서 옮긴다. 읽을 수 없거나 애매한 숫자는 **추측하지 말고** 물어보거나 '…'로 둔다.
- 같은 지표가 두 곳에서 다르면(예: 광고 관리자 전환 14 vs 자체 DB 11) 둘 다 적고 어느 쪽을 퍼널에 썼는지 메모에 남긴다. 퍼널은 가능한 한 자체 DB(실제 사람) 기준.
- 일별 방문에 그날 한 일(게시·광고 시작·가격 변경·메일 발송)을 표시한다. 사용자에게 "이번 주에 한 일 날짜별로"를 꼭 묻는다 — 이게 숫자와 원인을 잇는다.
- 방문(visits)과 방문자(visitors)를 섞지 않는다 — 출처 단위 하나로 퍼널 첫 단계·일별 막대를 맞추고 `daysTitle` 에 단위·출처.
- 퍼널이 같은 사람을 따라간 코호트가 아니면(이번 주 결제자 ≠ 이번 주 체험자일 수 있음) foot 에 한 줄.
- 개인 이름·이메일·전화번호는 싣지 않는다(고객사·교회·회사 이름 정도까지만, 사용자가 원할 때).

## 3. 보고서 만들기
- `references/template.html` 을 복사해 `REPORT` 객체만 바꾼다. CSS·렌더 함수는 건드리지 않는다(사용자가 바꾸라고 할 때만).
- `data` 형식은 `references/data-schema.md`. 기간 버튼: 지난 주차들 + 이번 주 + 전체 누적.
- headline 은 2~3문장: 이번 주 가장 큰 변화(첫 주면 기준선) → 왜 그렇게 됐나(그 주에 한 일) → 병목 한 곳.
- 병목 = 첫 칸(방문→첫 행동)을 뺀 가장 낮은 전환. `funnel.bottleneck` 에 넣어 그래프 빨강과 headline 을 맞춘다.
- 첫 주엔 기간 버튼 하나, 전체 누적은 2주차부터.
- `next`(다음 할 일)는 3~5개, 병목에 맞춘 것 위주. 숫자로 확인할 수 있게("첫 수업 참여 52% → 60%").
- 만든 뒤 브라우저로 한 번 열어 깨진 곳(빈 섹션, NaN, 넘치는 글자)을 확인한다.

## 4. 마감과 보관
- 주가 끝나면 그 주 `data` 를 `reports/weekly/YYYY-MM-DD.json` 으로 저장하고, 같은 HTML 에 기간 버튼을 하나 더한다. 지난 주 숫자는 고치지 않는다(고쳐야 하면 메모에 '마감 후 재집계' 라고 남긴다).
- 공유가 필요하면 HTML 한 장 그대로 보내거나 정적 호스팅(GitHub Pages·Vercel·Claude 아티팩트)에 올린다.

## 하지 않는 것
- 매주 디자인 바꾸기, 근거 없는 숫자 채우기, 광고 관리자 숫자를 실제 가입으로 단정하기.
